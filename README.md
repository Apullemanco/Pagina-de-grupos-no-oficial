# Pagina-de-grupos-no-oficial
Plataforma estudiantil independiente creada por y para la comunidad del Tecnológico de Monterrey, Campus Monterrey. Nuestro objetivo es centralizar el acceso a la información, estandarizar formatos y preservar la memoria histórica de los proyectos e iniciativas impulsados por las distintas mesas directivas a lo largo de sus gestiones.
