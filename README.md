# Grupos Estudiantiles Tec MTY (No Oficial)

> Plataforma independiente creada por y para la comunidad del Tecnológico de Monterrey, Campus Monterrey. Diseñada para centralizar información, estandarizar formatos y preservar la memoria histórica del impacto estudiantil gestión tras gestión.

---

## 📌 Contexto y Propósito

El ecosistema de grupos estudiantiles en Campus Monterrey genera cientos de iniciativas, eventos y documentos valiosos cada semestre. Sin embargo, el relevo de mesas directivas suele provocar pérdida de información, duplicación de esfuerzos y formatos dispersos.

Este proyecto surge como una iniciativa estudiantil independiente para resolver tres necesidades clave:

1. **Centralización:** Un directorio unificado donde la comunidad pueda descubrir qué hace cada grupo, sus mesas vigentes y canales de contacto.
2. **Estandarización:** Plantillas, formatos y guías operativas accesibles para facilitar la logística y transición de liderazgo.
3. **Memoria Histórica:** Registro de proyectos, eventos e impacto logrados por cada gestión a través de los años.

---

## 🚀 Características Principales

* **Directorio de Grupos:** Búsqueda y filtrado por área de impacto (académicos, liderazgo, acción social, culturales, etc.).
* **Histórico de Gestiones:** Registro estructurado de mesas directivas anteriores y sus proyectos clave.
* **Centro de Recursos:** Repositorio de formatos comunes, plantillas administrativas y guías de mejores prácticas.
* **Diseño Responsivo:** Optimizado para consulta ágil desde dispositivos móviles y de escritorio.
